Welcome to **Forge Notes**, a small example blog built with [Pageforge](/about/).
Posts here cover whatever the example happens to need: build systems, language
trivia, and a steady drip of half-formed opinions.

## What this example demonstrates

This example exercises a handful of Pageforge features that the `basic` example
intentionally skips:

- Pagination — the post list breaks into pages of two
- Syntax highlighting — code blocks are styled by `site_chroma_css`
- Template functions — dates run through `formatTime` instead of being printed raw
- Custom front-matter fields — `author` and `reading_minutes` flow through to templates
- A YAML-driven landing page that hand-picks featured posts

If you are reading the source, the BUILD files are the table of contents.
